    Kalibrierung

    1. Starten. Das Drehmoment geht aus, der Arm wird kraftlos. Arm festhalten! Die bisherigen Werte im Servo werden gemerkt; beim Abbrechen werden sie zurückgeschrieben.
    2. Mitte. Alle Gelenke von Hand in die Mitte ihres Bewegungsbereichs stellen, ungefähr wie in der Skizze (aus LeRobot): Oberarm senkrecht, Unterarm waagerecht, Handgelenk gerade. Dann übernehmen: Der Homing-Offset wird so ins EEPROM geschrieben, dass diese Stellung 2047 ergibt.

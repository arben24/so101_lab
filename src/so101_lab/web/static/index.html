    Servo-IDs vergeben

    Für neue Servos, bevor der Arm zusammengebaut wird. Unabhängig vom Gerät oben: Der Assistent öffnet den Port selbst, ein dort verbundenes Gerät muss vorher getrennt sein. ID und Baudrate werden dauerhaft ins EEPROM geschrieben und danach geprüft. Jede Aktion landet im Protokoll.

    Reihenfolge

    GelenkIDStand
    1. Genau einen Servo anschließen. Netzteil aus, einen Servo mit dem Adapter verbinden (noch nicht im Arm verbaut), Netzteil an. Neue Servos haben alle die ID 1: Hängen zwei am Bus, antworten beide gleichzeitig.
    2. Suchen. Alle Baudraten werden durchsucht, das dauert etwa 8 s. Es muss genau ein Servo antworten.

    3. ID schreiben. Ziel wählen: ein Gelenk (vorgeschlagen ist das nächste offene) oder eine freie ID für einen einzelnen Servo, etwa einen Ersatzservo oder einen eigenen Aufbau. Vor dem Schreiben wird der Servo mehrmals gelesen: Wackeln die Antworten, hängen vermutlich zwei Servos mit gleicher ID am Bus.

    4. Prüfen. Antwortet der Servo unter der neuen ID bei 1 Mbit/s, ist die alte ID frei, stehen die Register richtig?
      • Neustart-Probe (empfohlen). Netzteil aus und wieder an (oder Servo ab- und wieder anstecken). Erst das zeigt, dass ID und Baudrate wirklich dauerhaft im EEPROM stehen.
      • Beschriften, abziehen, nächster Servo. Einen Aufkleber mit ID und Gelenk auf den Servo kleben. Dann wieder bei Schritt 1 beginnen.
